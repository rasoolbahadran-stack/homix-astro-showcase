# هومیکس | Homix — نمونه‌کار فروشگاه اینترنتی لوازم خانگی

<div dir="rtl">

فروشگاه آنلاین تخصصی **لوازم خانگی**، طراحی‌شده با **Astro** و **TypeScript**، RTL و زبان فارسی،
کاملاً واکنش‌گرا و بهینه‌شده برای انتشار روی **GitHub Pages**. این پروژه یک **نمونه‌کار نمایشی
(Demo)** است و هدف آن نمایش توانمندی طراحی و توسعه یک فروشگاه اینترنتی حرفه‌ای است؛ هیچ
سفارش یا پرداخت واقعی انجام نمی‌گیرد.

> 🌐 **سایت منتشرشده:** https://rasoolbahadran-stack.github.io/homix-astro-showcase/

</div>

## ✨ ویژگی‌ها

<div dir="rtl">

- **طراحی مدرن و حرفه‌ای** — پالت Navy پریمیوم + Gold گرم + Teal اعتماد، تایپوگرافی Vazirmatn، فضای سفید اصولی و کارت‌های محصول دقیق.
- **RTL و فارسی** — تمام‌سطح، با ارقام فارسی و قالب‌بندی قیمت/تاریخ شمسی.
- **واکنش‌گرای واقعی** — بررسی‌شده از ۳۷۵px تا ۱۴۴۰px بدون Overflow افقی.
- **صفحه اصلی کامل** — Hero، دسته‌بندی‌ها، پرفروش‌ها، فروش ویژه با شمارش معکوس، پیشنهادهای ویژه، جدیدها، بنرها، برندها، مزایا، آمار، CTA.
- **فروشگاه با فیلتر/مرتب‌سازی** — فیلتر بر اساس دسته، برند، قیمت، تخفیف؛ مرتب‌سازی (پرفروش، جدید، قیمت، امتیاز)؛ جستجو؛ همگام با URL.
- **صفحه محصول** — گالری تصاویر، مشخصات فنی، ویژگی‌ها، تب‌ها، نظرات نمونه، محصولات مرتبط، انتخاب تعداد و افزودن به سبد.
- **سبد خرید واقعی** — ذخیره در `localStorage`، افزایش/کاهش تعداد، حذف، محاسبه مجموع و هزینه ارسال، بج سبد زنده.
- **انیمیشن‌های ظریف** — ورود تدریجی هنگام اسکرول (IntersectionObserver)، Stagger کارت‌ها، Hover Effects، Micro-interactions، احترام به `prefers-reduced-motion`.
- **SEO حرفه‌ای** — HTML سمنتیک، Meta/OG/Twitter، Canonical، Sitemap، robots.txt، Breadcrumb، **Structured Data** (Organization, WebSite, Product, ItemList, BreadcrumbList, FAQPage).
- **عملکرد بالا** — حداقل جاوااسکریپت (فقط تعاملات کلاینت)، تصاویر Lazy، فونت با `display: swap`، HTML فشرده، Prefetch لینک‌ها.

</div>

## 🌍 انتشار روی GitHub Pages

<div dir="rtl">

پروژه از طریق GitHub Action در `.github/workflows/deploy.yml` به‌صورت خودکار روی GitHub Pages منتشر می‌شود.
مراحل:

1. Push به شاخه `main`.
2. Workflow اجرای `npm ci` → `npm run build` → بارگذاری artifact `./dist`.
3. انتشار روی GitHub Pages.

**نکته Base Path:** چون انتشار روی مسیر پروژه‌ای (`/homix-astro-showcase/`) است، مقدار `base`
در `astro.config.mjs` به‌صورت خودکار بر اساس نام مخزن تنظیم می‌شود. در صورت استفاده از
دامنه اختصاصی، متغیر محیطی `BASE_PATH=/` تنظیم کنید.

**پیش‌نیاز:** در تنظیمات مخزن → Pages → Source باید `GitHub Actions` انتخاب شده باشد.

</div>

## 🔌 معماری Backend (آماده توسعه)

<div dir="rtl">

فرانت‌اند به‌صورت کاملاً Static روی GitHub Pages منتشر می‌شود (GitHub Pages از اجرای سرور Next.js
پشتیبانی نمی‌کند). معماری فرانت‌اند به‌گونه‌ای طراحی شده که اتصال به یک Backend واقعی
(بر پایه Next.js) در آینده بدون بازنویاسی ممکن باشد.

مخزن مدیریتی موجود (`cdanesh-admin-nextjs-showcase`) یک پنل مدیریت محتوای عمومی مبتنی
Next.js 15 است؛ Backend آن یک CRUD عمومی `[entity]` دارد اما مدل دامنه فروشگاه
(محصولات/سفارشات/موجودی) را پیاده‌سازی نکرده است و اتصال مستقیم آن به این فروشگاه نیازمند
توسعه قابلیت‌های فروشگاهی است. در نسخه نمایشی فعلی، داده‌ها به‌صورت نمونه و درون فرانت‌اند
تعریف شده‌اند.
